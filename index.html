yt-mcp-personal

yt-mcp-personal is a private, single-user tool. It runs only on its owner's own computer and helps the owner research public YouTube data and upload videos to the owner's own YouTube channel.

It is not a public service. It has no user accounts, no website login and no other users.

  • Uses the YouTube Data API (YouTube API Services).
  • Uploads happen only after the owner has reviewed and approved each video.
