Privacy Policy

Last updated: 6 October 2026

What this tool is

yt-mcp-personal is a personal tool used by a single person (its owner) on their own computer. It uses YouTube API Services. It is not offered to anyone else.

Data accessed

  • Public YouTube data (video, channel, playlist and comment information) retrieved through the YouTube Data API, and public video transcripts retrieved from youtube.com, for the owner's research.
  • The owner's own YouTube account, only after the owner signs in with Google and grants permission: to upload videos and thumbnails to the owner's channel, and to read the owner's basic channel information (channel name and ID) to confirm which channel is connected.

How data is used, stored and shared

  • Data is used only to provide the tool's functions to its owner.
  • The OAuth token is stored in a local file on the owner's computer. API responses and transcripts are cached in the owner's MongoDB Atlas database (hosted by MongoDB, Inc., EU/Frankfurt region) and are automatically deleted within 30 days.
  • Comment data may include public commenters' names; it is used only for the owner's research and is deleted within 30 days.
  • No data is sold or used for advertising. Data is shared only with service providers that run the tool for the owner: MongoDB (cache hosting) and Anthropic (the AI assistant that reads the tool's results). Google user data is not used to train AI models.
  • The tool stores one OAuth token file on the owner's computer. It uses no cookies, analytics or tracking technologies.

Google and YouTube

This tool uses YouTube API Services. By using it you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access granted to this tool can be revoked at any time via the Google security settings page. Revoking access stops all further use of the account; the owner then deletes the local token file.
